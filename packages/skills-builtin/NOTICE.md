# Bundled Skills — Notices

The skills under `skills/` are adapted from upstream open-source projects.
Each skill's `SKILL.md` carries its own `license` field; this file aggregates
the attributions.

## Adaptation

All skills were adapted to **pure-prompt form**: the original frontmatter's
tool/MCP declarations and any script/CLI execution references were removed, and
a GenOffice-specific `app` field was added to control which app loads each
skill. The instructional body (templates, rubrics, methodology) is preserved.
